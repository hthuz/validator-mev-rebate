# 2026-11-19

## 公共层：block JSON -> BlockTransaction 加载器

按 CLAUDE.md 分层，不改已有 `Transaction`（mitigation 的用户提交交易），新增独立类型。

- `type/models.py` + `type/__init__.py`：新增 `BlockTransaction` dataclass，字段严格只保留
  `signatures / message / fee / preBalances / postBalances / instructions / logMessages / timestamp`，
  再加区块 `slot`。`signature` property 取第一笔签名。
- `utils/utils.py` + `utils/__init__.py`：新增
  - `parse_block_transactions(block_data, slot=None)`：兼容 RPC 外壳 `result.transactions` 与裸结构；
    slot 优先级 显式参数 > JSON 内 slot > 抛 ValueError。
  - `load_block_transactions(block_file, slot=None)`：从文件加载，slot 默认从文件名解析
    （`block_346769956.json` -> 346769956）。
  - 注意 `type.validator` 反向 import `utils`，所以 `BlockTransaction` 在加载函数里**延迟导入**，
    不要在 utils 模块级 import type，否则循环依赖。
- `scripts/load_block_transactions.py`：示例脚本（脚本直接运行时要 sys.path.insert 项目根目录）。
  默认跑 `ref/block_346769956.json`，1734 笔交易，第一笔是 vote 交易，fee=5000。
- `tests/test_block_tx_loader.py`：7 个测试，覆盖两种 JSON 结构、字段白名单、slot 三种来源、真实 ref 样例。

验证：`pytest tests/ mitigation/tests/` -> 18 passed（唯一 warning 是原有 test_imports 返回 bool）。

备注：JSON 是 jsonParsed 编码（accountKeys 是 dict、instructions 带 parsed 字段）；
Go 版 collector.go 是 base64 编码，字段语义一致但编码不同。
mitigation/user/client.py 目前仍按裸 `block_data.get('transactions')` 取数，与 ref 的 RPC 外壳不匹配，
本次未改动（用户只要求公共层 loader）；后续接入时改用 `load_block_transactions` 即可。

## 全项目统一为 BlockTransaction（删除旧 Transaction）

- `type/models.py`：**删除 `Transaction` 类**；`TransactionRecord.tx_id` 也改名为 `signature`。
  `BlockTransaction` 新增 `to_dict()` / `from_dict()`，作为 client 发送和 server 构造的唯一序列化入口。
- `type/__init__.py`：移除 `Transaction` 导出。
- mitigation 全切换：`server.py`、`transaction_manager.py`、`strategy/*.py`、`user/client.py`
  全部改用 `BlockTransaction`。交易唯一标识统一用 `signature`（= signatures[0]），不再有 tx_id。
- `user/client.py`：改用公共 `load_block_transactions()` 按 slot 加载，发送时直接 `tx.to_dict()`。
  这同时修复了原来按裸 `block_data['transactions']` 取数、与 RPC 外壳 `result.transactions` 不匹配的问题。
- `/sendTransaction` 的响应和 `/transactions/sent` 的字段都由 `tx_id` 改为 `signature`；
  请求体不再校验 tx_id/signature，直接 `BlockTransaction.from_dict(data)`。
- 测试 test_strategy / test_server_init / test_imports / test_slot_protocol 全部同步。

验证：全库 grep 无 `Transaction` / `tx_id` 残留（仅剩 mitigation/__init__.py 的注释）；
`pytest tests/ mitigation/tests/` -> 18 passed；RPC 外壳格式的 E2E 跑通，3 slot × 2 笔交易全部按 signature 发送。
