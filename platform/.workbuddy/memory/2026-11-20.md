# 2026-11-20

## 新增「验证者视角」风险暴露指标（victim 评估）

需求：现有三档标签是 sandwich 口径（是否观测到 victim sandwich），缺一个从验证者角度看的指标——所有已发送交易里，有多少落在评估 epoch 认定的 risky leader 上。

改动：
- `mitigation/transaction_manager.py`：新增 `_landed_validators` Counter，每笔发送交易按落地 validator +1（immediate 也计入，不存逐笔详情），`get_report()` 输出 `landed_validators` 聚合字段，`clear()` 重置。
- `mitigation/evaluation.py`：新增 `load_risky_validators(epoch, loader, threshold)`（ratio 严格 > config 阈值，NaN/非法视为安全，默认读 replay epoch 自身 ratio）与 `evaluate_leader_risk_exposure(report, risky_validators)`（统计 total_sent / on_risky_leader / on_safe_leader 及占比）。
- `mitigation/sim.py`：victim 模式先打印「落地 leader 风险暴露」，再打印三档评估。
- `mitigation/tests/test_victim.py` +3 测试；README 更新两套指标说明。

口径区分：策略用历史 800-801 判风险，这套指标用 replay epoch 802 自身 ratio 判风险，是留出验证；两者不一致是预期结果。

验证：`python -m pytest tests/ mitigation/tests/ -q` -> 53 passed。真实数据冒烟（slot 346464132-346464160）：immediate 4/4 落在 risky leader（100%），risk-aware 0/4（0%），指标能区分策略效果；802 自身 risky validator 32 个（共 1092 有数据）。
